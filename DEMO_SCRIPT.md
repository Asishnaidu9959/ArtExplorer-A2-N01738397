# Suggested 5–7-minute narrated walkthrough

This is a recording plan, **not** a recorded demonstration.

- **0:00–0:40** — Introduce the assignment and personalized Home/About pages; explain the Met API.
- **0:40–1:30** — Browse artworks and Advanced Search; open an artwork detail page.
- **1:30–2:20** — Show guest restrictions, login, the HttpOnly cookie and Navbar session state.
- **2:20–3:30** — Add/remove favourites, watch the Navbar count change, and refresh to demonstrate persistence.
- **3:30–4:20** — Open My Favourites, edit a note (250 characters maximum), save and refresh.
- **4:20–5:00** — Save the light/dark theme in Profile, refresh and verify it remains selected.
- **5:00–5:50** — Compare student Access Denied and admin account directory; explain the backend 403 response.
- **5:50–6:40** — Show AuthContext, FavoritesProvider, MongoDB Atlas records and Postman CRUD/authorization evidence.

Before recording, confirm these behaviours on the **deployed Vercel URL**, not only localhost. Avoid showing any database passwords, JWTs or other secrets.
